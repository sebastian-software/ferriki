# Changelog

Ferriki's published npm packages (`@ferriki/core` with its platform sidecars and
`@ferriki/vite`) and Rust crates (`ferriki`, `ferriki-textmate`, and
`ferriki-asset-gen`) share one version and release changelog.

- Package changelog: [`node/ferriki/CHANGELOG.md`](node/ferriki/CHANGELOG.md)
- Tagged releases and their assets:
  [GitHub Releases](https://github.com/sebastian-software/ferriki/releases)

Both are generated from Conventional Commits by release-please; do not edit
release entries by hand. See
[`CONTRIBUTING.md`](CONTRIBUTING.md#commits-and-releases) for the commit
convention and [`docs/release-checklist.md`](docs/release-checklist.md) for the
release procedure.
