# Languages and themes

Ferriki provides Shiki's catalog: **260 TextMate grammars** and **65 themes**.
The package ships catalog metadata; grammar and theme payloads are downloaded
and cached on first use by an asynchronous API call.

See [Ferriki vs Prism](/guide/ferriki-vs-prism) for real TypeScript, TSX, C++, Go, Rust,
CSS, HTML, and Astro outputs, including the token distinctions available to themes.

## Standard languages

Name a language by its ID or one of its aliases (`ts`, `rs`, `sh`, …):

```js ferriki-check=catalogs
import { bundledLanguages, bundledLanguagesAlias, createHighlighter } from "@ferriki/core";

const highlighter = await createHighlighter({
  langs: ["typescript", bundledLanguages.rust],
  themes: ["github-dark"],
});

const html = highlighter.codeToHtml("const answer = 42", {
  lang: bundledLanguagesAlias.ts,
  theme: "github-dark",
});
highlighter.dispose();
```

Embedded languages load with their host: an HTML grammar brings the CSS and
JavaScript grammars it hands `<style>` and `<script>` blocks to, and a
Markdown grammar highlights fenced code in every language that is loaded.

## Themes

Use any key of `bundledThemes`, such as `github-light`, `github-dark`,
`nord` or `vitesse-dark`. The special theme `none` returns unstyled output.
For light and dark output from one call, pass a `themes` map:

```js ferriki-check=theme-map
import { createHighlighter } from "@ferriki/core";

const highlighter = await createHighlighter({
  langs: ["typescript"],
  themes: ["github-light", "github-dark"],
});
let html;
try {
  html = highlighter.codeToHtml("const answer: number = 42", {
    lang: "typescript",
    themes: { light: "github-light", dark: "github-dark" },
  });
} finally {
  highlighter.dispose();
}
```

`createCssVariablesTheme` builds a theme whose colors are CSS variables, for
sites that style highlighting from their own stylesheet.

For unchanged theme files with CSS classes instead of inline styles, see
[Class-based output](/guide/class-highlighting).

## Your own grammars and themes

A custom grammar or theme is the same JSON-shaped TextMate structure Shiki
accepts. Ferriki validates it before it reaches the native engine:

```ts
import myGrammar from "./my-language.tmLanguage.json" with { type: "json" };

await highlighter.loadLanguage({ ...myGrammar, name: "my-language" });
highlighter.codeToHtml(source, { lang: "my-language", theme: "github-dark" });
```

A language registration needs `name`, `scopeName` and valid patterns; a theme
needs `name` and valid settings. Aliases of your own apply to one
highlighter; the standard aliases cannot be overwritten.
