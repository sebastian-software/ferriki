# Compatibility

"Shiki-compatible" is checked, not claimed. Ferriki tracks one approved Shiki
release at a time, currently **Shiki v4.4.3**.

## How it is checked

- **A pinned mirror of Shiki.** Shiki's own tests run unchanged against
  Ferriki's native engine from an immutable mirror in the repository. Every
  mirrored file is recorded with its SHA-256 digest and verified before and
  after a test run; Ferriki-specific glue lives outside the mirror.
- **A pinned vscode-textmate oracle.** The tokenizer is a mechanical port of
  vscode-textmate v9.3.2, checked against vscode-textmate's own test cases.
- **Explicit exclusions.** Upstream tests outside Ferriki's scope are listed in
  a machine-checked manifest, each with its reason and owning issue.

The core gate covers the standard catalogs, language aliases, themes, HTML,
HAST and token output, lazily embedded grammars, injections, custom
registrations, multi-theme output and the public exports.

## Scope

| Area                                                             | Status                                                                                                  |
| ---------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------- |
| Highlighting runtime, `codeToHtml`, `codeToHast`, `codeToTokens` | Part of Ferriki                                                                                         |
| Transformers and decorations                                     | JavaScript hooks around the native pipeline; the `@shikijs/transformers` package is not part of Ferriki |
| `rehype`, `markdown-it` and other adapters                       | Outside Ferriki; they build on `codeToHtml` and `codeToHast`                                            |
| Browser runtime, WASM, engine selection                          | Not a goal                                                                                              |

## Platforms

Node.js 22.13.0 or newer, with a native binary per target:

| Target                               | Platform               | Status        |
| ------------------------------------ | ---------------------- | ------------- |
| `linux-x64-gnu`, `linux-arm64-gnu`   | Linux, glibc           | Supported     |
| `linux-x64-musl`, `linux-arm64-musl` | Linux, musl (Alpine)   | Supported     |
| `darwin-arm64`                       | macOS on Apple Silicon | Supported     |
| `win32-x64-msvc`, `win32-arm64-msvc` | Windows                | Supported     |
| `darwin-x64`                         | macOS on Intel         | Not supported |

The full policy, including how to report a gap, is
[docs/compatibility.md](https://github.com/sebastian-software/ferriki/blob/main/docs/compatibility.md).
