# ferriki-asset-gen

Binary manifest and asset codec used by Ferriki's Rust highlighter and asset
generation tools. The format version is checked at runtime; applications can
load catalogs from a directory or embed the generated bytes.

The format is documented in the repository's
[`docs/asset-format.md`](https://github.com/sebastian-software/ferriki/blob/main/docs/asset-format.md).
